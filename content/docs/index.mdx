## Why Proofline Exists

Generative AI marketing workflows generate compelling copy quickly, but frequently introduce factual drift:
- **Superseded rates**: Quoting old introductory tiers ($49/mo instead of active $69/mo).
- **Invented guarantees**: Turning a 99.9% target SLA into an "unconditional 99.99% uptime guarantee".
- **Missing disclaimers**: Omitting mandatory regulatory disclaimers regarding taxes or annual commitments.

When teams use language models to check other language models, hallucinations compound. Proofline solves this by treating truth as a **versioned register** governed by product and legal owners, verified through a strict 3-stage pipeline.

## 30-Second Developer Quickstart

<Steps>
<Step>
### Install via NPM

Install the core verification package into your project:

```bash
npm install @proofline/engine
```
</Step>

<Step>
### Run Verification in Node / Next.js

Import `verifyDraft` and test an arbitrary marketing sentence:

```typescript
import { verifyDraft } from "@/lib/verify";

const result = await verifyDraft(
  "Flowdesk Starter begins at ₹4,999 per month with 5 team workspaces.",
  "B-flowdesk",
  "2026-11-06"
);

console.log(result.summary);
// { total: 2, deterministic: 2, model: 0 }

console.log(result.findings[0].verdict);
// "CONTRADICTED"
// Reason: Active fact F-021 states ₹6,499/month (v4, effective 2026-04-01).
```
</Step>

<Step>
### Inspect Proof Pins

Every finding returned by Proofline contains full cryptographic provenance:

```json
{
  "fact_id": "F-021",
  "fact_version": 4,
  "source_document_id": "DOC-003",
  "source_span": [412, 468],
  "valid_from": "2026-04-01",
  "valid_until": "2027-03-31"
}
```
</Step>
</Steps>
